# NÃO FALA!

Jogo web mobile-first para grupos presenciais. Uma pessoa precisa fazer sua equipe adivinhar a palavra principal sem falar nenhuma das cinco palavras proibidas da carta.

## Recursos

- Modos Clássico, Relâmpago e Caos Leve
- 160 cartas originais em português brasileiro
- Seis temas visuais
- Equipes, jogadores, placar, revanche e desempate
- Cronômetro baseado em timestamp
- Sons, vibração, gestos e atalhos de teclado
- Persistência da partida no localStorage
- Manifest PWA básico

## Tecnologias

- Next.js com App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Executar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Validação

```bash
npm run lint
npm test
npm run build
```
